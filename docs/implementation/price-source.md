# Источник цены: инженерное состояние

**Статус на 15 сентября 2026:** для денежного раунда источник ещё не утверждён. В приложении и keeper сейчас используется `MOCK_ONLY`; это не live-рынок и не может открыть раунд с реальными средствами. Программа также инициализирует `Config.mock_only = true` и отклоняет `deposit` и `create_round`, поэтому этот запрет обеспечен не только интерфейсом.

Такой запрет намеренный: pump.fun bonding curve, мигрировавший Raydium-пул и Meteora DLMM — разные состояния токена. Нельзя подставить одно вместо другого только потому, что у них есть цена.

## Контракт адаптера

`services/keeper/src/price-adapter.mjs` фиксирует единственную точку подключения. Реальный адаптер обязан вернуть для каждого окна:

- адрес именно допущенного пула;
- цену в целой фиксированной единице, без JavaScript `number`;
- границы окна, число выборок, время наблюдения и ссылку/идентификатор исходных данных;
- достаточность покрытия окна, а не последнюю котировку.

Клиент не отправляет цену в программу. Keeper публикует P0/P1 только после `assertObservation`; программа принимает лишь цену от отдельной price authority и только для указанного Round/pool/времени.

## До включения real source

1. Выбрать один тип пула на реальных молодых токенах.
2. Зафиксировать P0/P1: интервалы, метод усреднения, фиксированную точность, допустимую давность и точную зону равенства.
3. Прогнать отсутствие сделок, миграцию, остановку пула, неполное окно и резкий ценовой ход.
4. Измерить глубину и определить общий cap, `MIN_BET` и `MAX_BET`.
5. Добавить воспроизводимые fixtures с tx/signatures и тест адаптера. Только после этого подготовить отдельную audited migration, которая заменит `MOCK_ONLY`; текущая программа намеренно не содержит admin-переключателя для обхода этой проверки.

## Временный mock

`pnpm --filter @flipthememe/keeper start` поднимает `GET /v1/arena/current` и `/v1/arena/current/observations`. Он нужен для разработки интерфейса и восстановления состояния; ответ маркирован `MOCK_ONLY` и не является доказательством рыночной цены.
