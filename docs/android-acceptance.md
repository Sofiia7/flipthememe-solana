# Android acceptance of audit fixes

`apps/mobile/e2e/smoke.yaml` is a Maestro navigation smoke flow for `com.flipthememe.app`. Run `maestro test apps/mobile/e2e/smoke.yaml` on the exact signed release candidate. It uses no practice bets, no wallet seed and no automatic wallet approval. It is provided but has not been run on a device in this workspace.

Physical acceptance must record APK SHA-256, versionCode, source commit, device/Android version, wallet and build manifest. Test 360/390/412 dp widths, short screen heights, system text 100/130/150%, TalkBack and Remove animations. Verify every actionable target has at least 48 dp, labels do not depend on colour, and the stage/sheets scroll when banners, a long token name and several active rounds coincide. Capture screenshots of Arena, Top up, Wallet, History, win/loss/refund and an expired invite. Native-text fallback replaces SVG lettering at enlarged text sizes.

Critical money flows (devnet test SOL only): first visitor UP/DOWN → delayed wallet approval past cutoff → successful topup but explicit NOT placed; approval while open → original amount/round; a smaller available amount → retap required; insufficient test SOL → faucet fallback; double tap; send followed by network loss or app kill; reopen and recover original signature without duplicate deposit/bet; reject approval; restore after reinstall using the same wallet; manual claim/refund after deadline; withdraw while new bets are paused; revoke all device sessions; close old session and return device gas. Also test Back inside wallet app, sheets, result and other tabs; cold/warm invite links and notification links; a second active round arriving just before the first resolves; token rotation with a failed previous image.

Do not label CI unit helpers as Android E2E. Do not publish a device-tested claim without this record. Keep public release and demo on the same APK. The manifest intentionally says physical acceptance is not attested by CI. Publishing a release must include `FlipTheMeme.apk` and `release-manifest.json` with the APK hash and exact source commit.
